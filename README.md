# Rishi's Restro- Food Menu Website

##  About The Project

Spice House is a simple and responsive restaurant food menu website.

The website displays different popular dishes in attractive food cards. Each card contains a food image, dish name, description, price, and an Add to Cart button.

The website has a clean, simple, and user-friendly design with a responsive layout.

---

## Aim

To create an attractive and responsive restaurant food menu section using HTML and Tailwind CSS Grid.

---

## Features

-  Home section
-  Food Menu section
-  Popular food cards
-  Indian Thali
-  Price badges
-  Add to Cart buttons
-  My Orders section
-  About Us section
- Contact section
-  Indigo color theme
-  Hover and transition effects
-  Responsive design
-  Responsive food images

---

## Technologies Used

- HTML5
- Tailwind CSS

**Note:** No custom JavaScript is used in this project.

---

## 📐 Tailwind CSS Concepts Used

The following Tailwind CSS utilities are used:

- `grid`
- `grid-cols-1`
- `md:grid-cols-2`
- `lg:grid-cols-3`
- `gap-8`
- `aspect-video`
- `object-cover`
- `rounded-2xl`
- `shadow-md`
- `hover:shadow-xl`
- `hover:-translate-y-1`
- `hover:scale-105`
- `transition-all`
- `duration-300`
